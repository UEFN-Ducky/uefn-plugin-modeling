# UEFN Modeling

Static mesh info and collision. Bundles the modeling skill.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`modeling`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/modeling-*.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
